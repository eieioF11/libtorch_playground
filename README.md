# libtorch_playground
libtorchの勉強用

## 環境構築
- https://pytorch.org/get-started/locally/
```bash
pip3 install torch torchvision torchaudio
```

## build
```bash
mkdir build
cd build
cmake ..
make
```
## run
```bash
cd build
./libtorch_ex
```
